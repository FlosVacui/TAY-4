# Правила для Claude в TAY-4

Это репозиторий ТАУ-4 — новой кроссплатформенной версии CONTROL из ТАУ-3. План — `docs/ROADMAP.md`, порядок работы — `docs/PROCESS.md`. Оба документа обязательны.

## В начале каждой сессии
1. Прочитать `docs/history/JOURNAL.md` (верхние записи), `docs/DECISIONS.md` и строки «В работе» и «Ждёт решения» в `docs/tracker/tracker.yaml`.
2. Перед подэтапом сделать запрос к графу: `/graphify query "<тема>"` по `graphify-out` этого репозитория, а для Delphi-кода и разбора оригинала — по `..\graphify-out`.

## Всегда
- **Подэтап проходит полный цикл:** задание по шаблону → исполнитель → ревью другим агентом → доработка (не больше трёх раундов) → приёмка → коммит → журнал → график → CHANGELOG → обновление графа.
- **Модель и effort субагента** задаются явно, по таблице ролей в PROCESS.md. Субагенты не коммитят.
- **Учёт ведётся только через** `python tools/tracker.py …` (без ключа `-I`: PyYAML и openpyxl стоят в пользовательских пакетах; список — `tools/requirements.txt`). Excel руками не правим, исключение — колонка «Комментарий»; перед сборкой выполняется `sync`. Если Excel открыт, сначала попросить пользователя закрыть его.
- **Развилки (Р-x) решает пользователь.** Варианты и рекомендацию записать в DECISIONS.md и спросить пользователя. Если к сроку ответа нет, действовать по колонке «Если ответа нет». Где там «Ждём ответа», без пользователя ничего не решается: работа идёт только по независимым подэтапам.
- **Отчёты ревью** называются `docs/reviews/RV-<подэтап>-<раунд>.md`. Замечания в них нумеруются `R-<подэтап>-<n>` сквозь все раунды.
- **Публикация** (push, создание репозитория на GitHub, релизы) — только с подтверждения пользователя.
- **Материалы оригинала ТАУ-3 в репозиторий не кладём:** exe, `.HLP`, декомпилят, снимки окон, дословный текст справки.
- **Числа сравниваем только с допусками** из `docs/testing/tolerances.md`. Эталоны лежат в `fixtures/`.

## Эталоны и Delphi
- **Delphi-версия заморожена:** метки `v1.1-exact` и `v2-delphi-final` в `..\CONTROL_src`. В Delphi развивается только ветка `oracle`, она выдаёт эталонные числа.
- **Сборка Delphi** идёт только через IDE: `..\work\control\tools\build.py`.
- **Ловушки Delphi** (FPU `$1332`, UTF-8 с BOM, снимки окон) описаны в `..\HANDOFF.md` и `..\CONTROL_src\README.md`.
