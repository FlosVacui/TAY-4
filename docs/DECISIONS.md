## Подробно

### Р-0. Название
- **Варианты:**
  1. «ТАУ-3 NG» (NG — new generation);
  2. «ТАУ-3М» (модернизированный);
  3. «ТАУ-3 2027»;
  4. своё название.
- **Рекомендация.** Вариант 1. Название узнаётся на кафедре, а CONTROL станет одним из модулей будущего ТАУ-3.
- **Что зависит.** Имя репозитория на GitHub, заголовки окон, установщики. Переименовать дёшево только до публикации.

### Р-6. Лицензия и авторство
- **Варианты лицензии на свой код:**
  1. MIT или Apache-2.0 — разрешительные;
  2. GPL-3.0 — копилефт;
  3. без открытой лицензии («все права защищены»), но репозиторий публичный.
- **Обязательно при любом варианте:**
  - упомянуть авторов ТАУ-3 (Лозинский, Берщанский);
  - не выкладывать материалы оригинала;
  - справку писать своими словами.
- **Рекомендация.** Apache-2.0 или MIT; окончательно — после Р-2. Если выберем Qt, лицензии его модулей могут потребовать GPL.
- **Что зависит.** Публикация на GitHub, а значит, CI на Linux и macOS: мини-CI 2.2 (с 10.11) и замеры на трёх ОС в 2.3–2.4. Для публикации нужны Р-0 и Р-6, а также имя и e-mail автора коммитов. Сейчас локальные коммиты `tau3-ng` подписаны так же, как в Delphi-репозиториях (`FlosVacui`); до публикации их можно переподписать.

### Р-8. Языки интерфейса
- **Рекомендация.** Только русский в 1.0, но строки с первого дня выносятся в файлы локализации. Английский — в 1.x, если понадобится.
- **Решение пользователя (02.11.2026).** Русский и английский уже в 1.0.
- **Последствия:**
  - интерфейс, сообщения об ошибках и встроенная справка готовятся на двух языках (подэтапы 6.7, 6.8, 9.3);
  - термины английской версии — по стандартной англоязычной терминологии ТАУ, их таблица — в глоссарии (подэтап 3.2);
  - комплект ЕСПД — только на русском (ГОСТ).

### Р-0. Решение
Пользователь выбрал название **TAY-4** (02.11.2026). В русском тексте пишется «ТАУ-4», латиницей — TAY-4, как папка оригинала `TAY_3`. Папка и репозиторий называются `TAY-4`, модуль — CONTROL.

### Р-9. Веса критериев стека
Критерии, обязательные условия и веса — в [requirements/stack-criteria.md](requirements/stack-criteria.md) (подэтап 1.0, 03.11.2026). Они выведены из нефункциональных требований [SRS.md](requirements/SRS.md).
- **Варианты:**
  1. рекомендуемый набор весов;
  2. «Упор на расчёт» — больше вес точности, скорости и надёжности;
  3. «Упор на показ» — больше вес интерфейса, печати и установки на ПК кафедры;
  4. свои веса.
- **Рекомендация.** Вариант 1. Два других набора всё равно считаются в 2.1 для проверки устойчивости итога.
- **Решение пользователя (03.11.2026).** Рекомендуемый набор.
- **Вместе с весами пользователь ответил на вопросы из SRS:**
  - В-3: обязательна macOS на Apple Silicon, Intel — желательно;
  - В-2: на Linux и macOS хватит PDF, прямая печать с предпросмотром обязательна только на Windows.
- **Что зависит.** Сравнение 2.1 начинается по графику, с 10.11. «Упор на расчёт» и «Упор на показ» считаются там же для проверки устойчивости итога.

### Р-1. Причуды оригинала
Перечень — [requirements/quirks.md](requirements/quirks.md) (подэтап 1.7): 30 причуд в четырёх группах, у каждой группы свой вопрос. По умолчанию ТАУ-4 считает и ведёт себя правильно. Методы 1.1 (Бэрстоу, Паде 2/4, РК4 с постоянным шагом) остаются в переключаемом режиме совместимости, чтобы сверяться со старыми методичками.
- **Варианты:**
  1. по группам, как рекомендует перечень: режим совместимости повторяет методы 1.1 и причуды Q-003 (абсолютный порог Рауса), Q-004 и Q-005 (таблица частот), Q-007 (ноль пустой строкой), Q-009 (шаг осей); остальные 25 исправляются везде;
  2. исправить всё везде: режим совместимости повторяет только методы 1.1;
  3. как можно ближе к оригиналу: режим совместимости повторяет все причуды, которые можно повторить (кроме зависящих от пикселей экрана, Q-006);
  4. решить по отдельным записям.
- **Рекомендация.** Вариант 1. Повторяется только то, что видно в числах и нужно для сверки с методичками; неудобства интерфейса не повторяются.
- **Что зависит.** Состав режима совместимости (NFR-ACC-003) на этапах 5–6, сверка с оракулом Delphi (1.4), отложенные R-1.1-12 и R-1.1-14.

### Р-2, Р-3. Стек и веб-версия
Сравнение — [ROADMAP.md](ROADMAP.md), этап 2. Решение принимаем после набросков 2.4 и записываем в ADR-0001.

### Р-4. Дизайн
Три концепции с макетами — подэтап 3.3.

### Р-7. Подпись установщиков
Подпись для macOS требует Apple Developer ($99 в год), для Windows — сертификат. Оплатить их из РФ может быть непросто. Без подписи Windows показывает предупреждение SmartScreen, macOS — Gatekeeper. Это решается инструкцией по установке и переносными сборками.

### Р-5. Расширения в 1.0
Кандидаты — [ROADMAP.md](ROADMAP.md), этап 7. Решаем после сквозного среза 4.6.
