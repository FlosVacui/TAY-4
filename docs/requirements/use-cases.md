# Сценарии использования (UC) по лабораторным и домашним заданиям

Подэтап 1.6. По этим сценариям ворота 6.9 проверят, что ТАУ-4 годится для занятий кафедры, а этап 8 проведёт юзабилити-тест. Числа из «Ожидаемого результата» потом проверит оракул mpmath (1.5).

## Соглашения

- **Источники — пересказ.** Методички и скиллы кафедры пересказаны; дословных цитат нет. Снимков окон ТАУ-3 здесь нет.
- **Только CONTROL.** LINSYS, IMPULS, PHASPL, MVACS2 — другие программы ТАУ-3. Их шаги не описаны; где в работе есть такая часть, это сказано отдельно.
- **Числа — точные, без шума.** Скиллы кафедры выдают «измерения» с погрешностью отсчёта курсором; здесь только расчётные значения (Python: numpy, scipy, mpmath). Так работает и ТАУ-4: Паде и пороги режима совместимости (Р-1) на эти сценарии, по оценке, не влияют, но это не проверено (ОВ-UC-8).
- **Точность.** Аналитические числа даны с 5 значащими цифрами. Числа процесса (σ, tр, tmax) получены численно на сетке 2·10⁻⁴ с; их погрешность не больше 5·10⁻⁴ с, а σ точна до 4 цифр. Допуски для проверки программы берутся из `docs/testing/tolerances.md`, а не отсюда.
- **Окно процесса.** По FR-PRC-003 длина окна «Процесс регулирования» по умолчанию 10 с (а при самой большой Re корней меньше −0,6 — 6/|maxRe|, округлённо до 0,1 с). Показатели панели считаются по правилу FR-QLT-001: y∞ — среднее по последним 5 % точек кривой, а не hуст. Поэтому в сценариях, где процесс долго затухает, первым шагом задаётся длина окна («Выбор области», «до» не больше 50 с); числа в UC даны для этого окна. Принято допущение: кривая из 1001 точки. В FR число точек кривой не задано; в режиме 1.1 их около 20/шаг ≈ 2000 (FR-PRC-006), на 2001 точке σ меняется не больше чем на 0,015 процентного пункта. Число точек нужно зафиксировать в FR и связать с допусками 1.3 (ОВ-UC-9); из-за сетки σ в панели может отличаться от аналитической в третьей-четвёртой цифре (до 0,02 процентных пункта).
- **Звенья и буквы.** Обозначения W, R, H, G, N, f, A, B — по `docs/glossary.md`. Номера типов звеньев — по FR-SCH-009…012. По умолчанию H = 1, f = 1 (FR-SCH-008).
- **Язык и платформа.** Каждый сценарий проходится в русском и в английском интерфейсе (Р-8, NFR-L10N-001) и даёт одинаковые числа на всех ОС (NFR-ACC-002).
- **Сквозные шаги.** В начале любого UC: запустить программу (FR-UI-001), собрать схему, при желании сохранить вариант (FR-FIL-006, FR-FIL-010). В конце: снять рисунки и таблицы в файл (FR-OUT-010, FR-OUT-011, FR-OUT-001).

## UC-01. Частотные характеристики звена второго порядка (расчётный аналог ЛР-1)

**Название и цель.** Построить в CONTROL АФХ, АЧХ, ЛАЧХ и ЛФЧХ звена K/(a₂p² + a₁p + 1) и получить в тех же точках ω, что и в таблице ЛР-1, значения A, φ, L, U, V. Студент сверяет с ними свои «измерения» из LINSYS.

**Источник.** Методичка ч.1, ЛР-1 (с. 7–16, выдержка в скилле `tau-lab-freq`, `references/lab1.md`, `metodichka.md`). Опыт ЛР-1 идёт в LINSYS и здесь не описывается. Расчётная часть та же, что в аналитической части скилла.

**Исходные данные.** a₂ = 2,9; a₁ = 0,85; K = 2; Um = 0,8 (вариант из образца). Допустимо: a₂ 1…4, a₁ < 1,41·√a₂ (условие ξ < 0,707, при котором есть резонанс; например, a₂ 2…4, a₁ 0,5…1,2), K 1…5. Период T₀ = 90·√a₂, T₁ = 12,5·√a₂, Tᵢ₊₁ = 0,81·Tᵢ, 15 точек; ωᵢ = 2π/Tᵢ.

**Шаги.**
1. Собрать схему: W — общий многочлен (тип 12): K = 2, числитель b₈ = 1 (остальные bᵢ = 0), знаменатель a₇ = 2,9, a₈ = 0,85, a₉ = 1 (остальные aᵢ = 0); R = 1, G = 0, H = 1 (тип 1, K = 1 в R). Либо задать то же звено формулой (FR-SCH-015).
2. Открыть «Критерий Найквиста»; в окне «Частоты» задать отметки ω₀…ω₁₄ (диапазон и шаг подобрать так, чтобы попали нужные точки; точные ωᵢ из таблицы ниже читать курсором), в «Разомкнуть систему» выбрать точку h. Получить АФХ с равным масштабом осей.
3. Поставить курсор на отметки и записать ω, Re W, Im W.
4. Открыть «ЛАЧХ, ЛФЧХ» (точка h). Курсором на тех же частотах записать L и φ.
5. Открыть «Таблицу частот»: записать частоту среза и признак «критической частоты нет» (фаза не доходит до −180°).
6. Открыть «Амплитудно-частотная характеристика» (замкнутая система при H = 1 — для справки) или разомкнуть: H = 0, тогда АЧХ даёт |W| звена; найти максимум и ωр.

**Ожидаемый результат.** ξ = a₁/(2√a₂), ω₀ = 1/√a₂, ωр = ω₀√(1 − 2ξ²), Amax = K/(2ξ√(1 − ξ²)), M = Amax/K; A = K/√D, φ = −arctg(a₁ω/(1 − a₂ω²)) − 180° при ω > ω₀, D = (1 − a₂ω²)² + a₁²ω².
- ξ = 0,24957; ω₀ = 0,58722 рад/с; ωр = 0,54943 рад/с; Amax = 4,1378; M = 2,0689.
- A(ω₀) = K/(a₁ω₀) = 4,0069, φ(ω₀) = −90°, L(ω₀) = 12,056 дБ.
- Частота среза (|W| = 1): ωс = 0,98544 рад/с, φ(ωс) = −155,24°, запас по фазе 24,76°. Критической частоты нет.
- L(0) = 20·lg K = 6,0206 дБ.

## UC-02. Колебательное звено: семейства по ξ (ЛР-2)

**Название и цель.** Изучить переходную функцию h(t), АЧХ, АФХ, ЛАЧХ и ЛФЧХ звена K/(T²p² + 2ξTp + 1) при нескольких ξ и получить показатели каждой кривой семейства.

**Источник.** Методичка ч.1, ЛР-2 (с. 17–23), скиллы `tau-lab-oscill` (`references/lab2.md`) и `tau-lab-freq` (`references/metodichka.md`).

**Исходные данные.** K = 4,2; T = 1,2 с; ξ = 0,2; 0,35; 0,55; 0,8 (набор по умолчанию скилла; ξ в программе — буква A). Допустимо: K 1…10, T 0,2…5, ξ из (0; 1). Методичка просит 10–12 отметок на АФХ, образец и скилл дают 7; ТАУ-4 должна позволять любое число отметок. АФХ: 7 отметок ωᵢ = 0,25·i, i = 0…6 (последняя 1,5 рад/с ≈ 1,8/T), одинаковых для всех ξ.

**Шаги.**
1. Собрать схему: W — звено высокого порядка с запаздыванием (тип 9): K = 4,2; τ = 0; T₁ = T₂ = T₃ = 0; T₄ = 1,2; λ = A. Это K/(T₄²p² + 2λT₄p + 1). R = 1, G = 0, H = 0, f — единичная ступенька.
2. «Процесс регулирования»: в «Значениях» задать A = 0,2, в «Выберите функцию» оставить y. Задать область процесса («Выбор области»): t от 0 до 50 с, y от 0 до 7 (по умолчанию y от −2 до 3, а максимум h при K = 4,2 доходит до 6,41; по FR-GRF-006 часть кривой вне поля не рисуется). Окно 50 с нужно потому, что при ξ = 0,2 затухание медленное (η = 0,167, tр = 16,5 с), и в окне по умолчанию 10 с панель вместо tр напишет «процесс не установился». Построить h(t). Повторить для остальных ξ, закрепляя каждую кривую (семейство, легенда).
3. «Амплитудно-частотная характеристика»: то же для четырёх ξ; границы одинаковы («Выбор области», ω 0…4/T).
4. Перейти к H = 1. «Критерий Найквиста»: «Значения» (A = ξ), «Частоты» (от 0, до 1,5, шаг 0,25), «Разомкнуть систему» — точка h. Закрепить кривые четырёх ξ в одном окне.
5. «ЛАЧХ, ЛФЧХ» (точка h): те же четыре ξ; диапазон частот одинаков (0,1/T…10/T).
6. Для каждого ξ поставить курсор на максимум АЧХ, на первый максимум h(t), на частоту среза ЛАЧХ.
7. Открыть панель «Показатели» процесса и АЧХ (σ, tр, M, ωр).
8. Вывести рисунки на печать с предпросмотром (векторный экспорт) в натуральную величину.

**Ожидаемый результат.** Формулы: ωр = √(1 − 2ξ²)/T (есть при ξ < 0,7071); Amax = K/(2ξ√(1 − ξ²)); M = Amax/K; σ = 100·exp(−πξ/√(1 − ξ²)) %; tmax = πT/√(1 − ξ²); hmax = K(1 + σ/100); η = ξ/T; μ = √(1 − ξ²)/ξ (корни знаменателя); ωс — решение |W(jω)| = 1; запас по фазе 180° + φ(ωс). Для tр — последний выход за ±5 % от K.

## UC-03. Критерий Найквиста: критический коэффициент усиления (ЛР-3, часть 1)

**Название и цель.** Найти критический коэффициент усиления Kкр статической и астатической систем двумя способами (критерий Гурвица и АФХ при K = 1) и убедиться, что они совпадают.

**Источник.** Методичка ч.1, ЛР-3 (с. 24–31; выдержка в скилле `tau-lab-freq`, `references/metodichka.md`), скилл `tau-lab-nyquist` (`references/work.md`, `references/samples.md`).

**Исходные данные.** T₁ = 1,17; T₂ = 0,73; T₃ = 0,37 с (T₁ > T₂ > T₃; порядок в ЛР-3 выдержка не задаёт, он взят из требования ЛР-4; вариант из образца, для схемы А порядок звеньев не влияет на Kкр, для схемы Б влияет, см. ОВ-UC-7). Допустимо: T₁ 0,5…3, T₂ 0,3…1,5, T₃ 0,05…1. Схема А (статическая): R = 1/(T₁p + 1), W = K/((T₂p + 1)(T₃p + 1)). Схема Б (астатическая): R = 1, W = K/(p(T₂p + 1)(T₃p + 1)); интегратор заменяет звено с наибольшей постоянной времени.

**Шаги.**
1. Схема А: R — инерционное единичное звено (тип 10, T = 1,17); W — тип 5 (K = A, τ = 0, T₁ = 0,73, T₂ = 0,37); H = 1; G = 0.
2. «Критерий Рауса» (сетка по A, значения A от 0 до 12 с шагом 1 и выбор клетки) и «Определители Гурвица»: найти границу, где последний определитель меняет знак.
3. «Критерий Найквиста» при A = 1: «Частоты» оставить пустыми, «Разомкнуть систему» — точка h. Курсором на пересечении АФХ с осью Re записать частоту ω₁ и Re W(jω₁). Kкр = 1/|Re W(jω₁)|.
4. «Корневой годограф» по A от 1 до 12: «Таблица корней» и панель «Показатели»: Kкр и частота выхода корней на мнимую ось.
5. Схема Б: W — тип 4 (K = A, T = 0, T₁ = 0,73, T₂ = 0,37, τ = 0), R = 1. Повторить шаги 3–4. Заметить дугу бесконечного радиуса у начала координат.

**Ожидаемый результат.**
- Схема А. Характеристический многочлен: 0,316017·p³ + 1,5571·p² + 2,27·p + (1 + K). Условие Гурвица: 1,5571·2,27 > 0,316017·(1 + K). Kкр = (T₁ + T₂)(T₁ + T₃)(T₂ + T₃)/(T₁T₂T₃) = 10,1849. Частота ω₁ = √((T₁ + T₂ + T₃)/(T₁T₂T₃)) = 2,6801 рад/с. При K = 1: Re W(jω₁) = −0,098185 = −1/Kкр.
- Схема Б. Kкр = (T₂ + T₃)/(T₂T₃) = 4,0726; ω = 1/√(T₂T₃) = 1,9241 рад/с; Re W(jω) при K = 1: −0,24555.
- Ориентир: образец кафедры даёт 10,18 и 4,07 (см. ОВ-UC-1).

**Проверяемые требования.** FR-SCH-009, FR-SCH-011, FR-INP-014, FR-INP-015, FR-INP-017, FR-INP-018, FR-RTH-001, FR-RTH-002, FR-RTH-004, FR-RTH-005, FR-RTH-007, FR-ROO-001, FR-ROO-002, FR-ROO-003, FR-ROO-009, FR-ROO-010, FR-FRQ-001, FR-FRQ-002, FR-FRQ-007, FR-FRQ-008, FR-FRQ-009, FR-FRQ-013, FR-GRF-010, FR-GRF-011, FR-GRF-012, FR-QLT-005, FR-QLT-006, FR-QLT-007, FR-OUT-011.

**Что фиксирует снимок.** Общий вид АФХ и увеличенное пересечение с осью Re (курсор с отсчётом) для схем А и Б; таблица Гурвица (или Рауса); «Таблица корней» на границе устойчивости.

## UC-04. Запаздывание: запасы устойчивости и τкр (ЛР-3, часть 2)

**Источник.** Методичка ч.2, ЛР-4 (с. 23–34, пункт про непрерывный аналог), скилл `tau-lab-digital-pi` (`references/work.md`, `references/samples.md`). Годографы, таблицы корней в z-плоскости и процессы дискретной системы идут в IMPULS, вне CONTROL; в сценарии эти числа заданы как исходные данные.

**Исходные данные.** Непрерывная часть W = 1/((T₁p + 1)(T₂p + 1)(T₃p + 1)); T₁ = 0,33; T₂ = 0,68; T₃ = 1,41 с (образец). Период T₀ = T₁/4 = 0,0825 с; результат дискретного расчёта (из IMPULS): K₁ = 0,762; K₂ = 0,0466 (заданная колебательность μзад = 1,28). Для аналога K₂ аналог = K₂/T₀ = 0,56485. Допустимо: другие T, K₁ и K₂ из того же расчёта.

**Шаги.**
1. Собрать схему: W — общий многочлен (тип 12): K = 1, числитель b₈ = 1, знаменатель a₆ = 0,316404, a₇ = 1,6485, a₈ = 2,42, a₉ = 1 (раскрытое произведение (T₁p + 1)(T₂p + 1)(T₃p + 1); остальные aᵢ = 0); R — реальный ПИД (тип 2): K₁ = 0,762; K₂ = 0,56485; K₃ = 0; T = 0; H = 1. Либо задать W произведением формулой (FR-SCH-015).
2. «Процесс регулирования» (f — единичная ступенька, y). Задать длину окна 40 с (η = 0,52; в окне по умолчанию 10 с y∞ = 0,9943 вместо 1 и σ завышено до 8,72 %). Панель «Показатели»: σ, tр.
3. «Таблица корней»: η, μ.
4. Записать результаты рядом с расчётом дискретной системы из IMPULS.

**Ожидаемый результат.**
- Корни замкнутой системы: −3,3946; −0,77399; −0,52075 ± j0,63897.
- η = 0,52075; μ = 1,2270 (при μзад = 1,28 для дискретной системы; различие допустимо, это разные системы).

## Замечания к FR

1. **Kкр по годографу (FR-QLT-006).** Значение A на границе устойчивости находится линейной интерполяцией между двумя шагами сетки A. Точность Kкр поэтому зависит от шага; для UC-03 и UC-05 (Kкр = 10,1849) нужен либо допуск, привязанный к шагу, либо уточнение (деление пополам по Re = 0). Решить в 1.3.
2. **Окно процесса по умолчанию (FR-PRC-003, FR-QLT-001).** Окно 10 с (или 6/|maxRe|) и оценка y∞ по последним 5 % кривой дают неверные σ и tр для работ ЛР-2 и ЛР-4: для UC-05 при K = 0,4·Kкр σ = 48,76 % вместо 46,53 %, tр = 8,46 с вместо 7,14 с; для UC-02 при ξ = 0,2 — «процесс не установился»; для UC-06 и UC-09 расхождение 1,4…0,6 пп. Студент должен сам удлинить окно (до 50 с). Предложение: брать y∞ из передаточной функции (W(0) замкнутой системы) либо удлинить окно по умолчанию (например, до 6/η, но не меньше 30 с). Жёсткий предел «до» ≤ 50 с этими сценариями не опровергается: самый медленный случай (tр = 16,5 с) укладывается с запасом.
3. **Автоколебания в процессе.** FR-QLT-001 считает показатели переходного процесса, а для периодических колебаний пишет «процесс не установился». Для UC-07 нужны амплитуда и период по последним колебаниям. Предложение: режим «автоколебания: амплитуда, период, ω» в панели «Показатели».
4. **Подбор параметра по цели (UC-06).** K, дающий заданное M, студент подбирает вручную. FR-GRF-029 даёт семейство, но не решение. Предложение: команда «Найти A, при котором показатель = …» хотя бы для M, tр и σ.
5. **Семейство по A с неравномерными значениями (UC-02).** FR-GRF-029 строит семейство только по сетке (от, до, шаг), не больше 12 кривых. Набор ξ = 0,2; 0,35; 0,55; 0,8 сеткой не является; кривые приходится закреплять по одной (FR-GRF-028). Предложение: разрешить список значений A.
6. **Названия параметров реле (FR-SCH-022).** В методичке реле с зоной описано параметрами «порог c» и «уровень выхода b», а тип 2 имеет параметры c, a, b, α, где c — уровень выхода, а зона — a = b. Имена не совпадают и сбивают студента (ОВ-UC-3). Предложение: подсказка к полям (FR-HLP-008) с соответствием.
7. **Частота среза для отметок (UC-04).** Отметки ωк/6…ωк требуют знать ωк до построения Найквиста. В FR ωк даёт «Таблица частот» только из окна ЛАЧХ (FR-FRQ-019). Предложение: показывать частоту среза в окне Найквиста или открывать «Таблицу частот» и оттуда.
8. **Режим 1.1 и UC.** Для проверки режима совместимости (NFR-ACC-003) нужны отдельные ожидаемые числа: Паде для UC-04, абсолютный порог Рауса для UC-03, корни по Бэрстоу–Ньютону для UC-05. В этих сценариях различия, по оценке, меньше допуска, но числа не считались (ОВ-UC-8).
9. **FR-FRQ-012.** В файле снят как дубликат FR-INP-018. В сценариях используется FR-INP-018.

## Открытые вопросы

- **ОВ-UC-1.** Образец кафедры и скилл расходятся с точным расчётом: Kкр статической системы в скилле 10,18479, точный расчёт 10,184895; K астатической системы по M в образце около 0,94, точный 0,92058. Скорее всего, это округление и отсчёт курсором; без листа Mathcad образца не установить. Для оракула берутся точные числа этого документа.
- **ОВ-UC-2.** Образец кафедры даёт ωк = 1,68, γ = 34,2°, τкр = 0,355 для K = 4,073, а точный расчёт — 1,6714, 34,688°, 0,36223 (отличие около 2 %). Причина (отсчёт курсором или иное определение запаса) без методички целиком не ясна.
- **ОВ-UC-3.** Параметры типа 2 для реле с зоной «порог 1,8, выход 2,1» (c = 2,1, a = 1,8, b = 1,8) выведены по FR-SCH-022 (при b ≤ a звено работает как реле с зоной), но запуском программы не проверены. То же для типа 6 с T = 0 как интегратора (UC-06) и типа 9 с нулевыми T₁…T₃ (UC-02).
- **ОВ-UC-4.** Нужен ли ТАУ-4 режим «периодический сигнал на входе» из LINSYS (опытная часть ЛР-1)? Без него опыт ЛР-1 остаётся в ТАУ-3. Вопрос к заказчику (кафедре).
- **ОВ-UC-5.** Сценарий для весовой и переходной функций по FR-ANL-012: нужны вариант карточки («Задание 2») и порядок работы в окне «Анализ». Скилл `tau-lab-weight` описывает только LINSYS.
- **ОВ-UC-6.** ЛР-5 и ЛР-6 ч.1 (оптимальный ПИ, многосвязная САУ) не вошли в задание 1.6. Для сценариев нужны числа из методички целиком и отдельные скиллы; ЛР-5 проверила бы область MIN.
- **ОВ-UC-7.** Выдержка ЛР-3 для астатической схемы говорит «вместо первого звена» и порядок T не задаёт. Порядок T₁ > T₂ > T₃ требует выдержка ЛР-4; при нём «первое» и «наибольшее» совпадают. Образец кафедры (Kкр 4,07) согласуется с заменой звена с наибольшей T; в строке запуска скилла порядок T возрастающий (0,37; 0,73; 1,17), там «первое» дало бы 2,2246. Kкр зависит от выбора: замена звена с T = 0,37 даёт 2,2246; с T = 0,73 — 3,5574; с T = 1,17 — 4,0726 (принято в UC-03). Нужна методичка целиком.
