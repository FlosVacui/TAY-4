# Реестр рисков

Вероятность (В) и влияние (Вл) оцениваются как низкая, средняя или высокая. Реестр пересматривается на воротах каждого этапа.

| ID | Риск | В | Вл | Что делаем |
|---|---|---|---|---|
| РС-01 | Числа ядра на `f64` расходятся с Delphi Extended сильнее допусков | средняя | высокая | Политика допусков (1.3), double-double в плохо обусловленных местах, mpmath решает спорные случаи |
| РС-02 | Разрывные результаты (реле, оптимум минимума, клетки Рауса) переключаются от последнего знака | высокая | средняя | Сравнение по показателям и моментам, разбор почти равных значений (1.3) |
| РС-03 | Разные ОС дают разные биты (разные libm, FMA) | средняя | средняя | libm на чистом Rust, FMA выключен, CI сравнивает биты на трёх ОС |
| РС-04 | Delphi CE не собирается (лицензия на год, сборка только из IDE), а ветку `oracle` нужно собирать | средняя | высокая | Снять эталоны 1.4 заранее и с запасом; хранить готовые exe оракула локально |
| РС-05 | Пользователь не успевает принять решения к сроку | средняя | высокая | Срок и действие по умолчанию у каждой развилки; до решения ведём независимые работы |
| РС-06 | Недельные лимиты Opus тормозят ревью уровня 1 и ворота | средняя | средняя | Ревью разной глубины по риску. Opus — только там, где он назначен в ROADMAP: уровень 1, ворота, математика, архитектура, сравнение стеков и ключевые документы. Остальное — Sonnet и Haiku |
| РС-07 | Веб-движки (Tauri) рисуют и печатают по-разному | средняя | средняя | PDF и SVG генерирует ядро; печать проверяется в набросках 2.4 |
| РС-08 | Нарушение прав авторов ТАУ-3 в публичном репозитории | низкая | высокая | Материалы оригинала не публикуются, справка пишется своими словами, авторы указываются (Р-6) |
| РС-09 | Подпись установщиков нельзя оплатить из РФ | высокая | низкая | Неподписанные сборки с инструкцией и переносные сборки (Р-7) |
| РС-10 | Скиллы tau-lab-* перестанут работать, если заменить оригинал | низкая | средняя | Оригинал ТАУ-3 не трогаем; для новой программы — CLI и Python API (7.8) |
| РС-11 | Ревьюеры одной семьи моделей пропускают одни и те же ошибки | средняя | средняя | Проверки без LLM (мутации, фаззинг, оракулы), внешние нейросети (ВН) на ключевых местах |
| РС-13 | Два языка в 1.0 (Р-8) увеличивают объём этапов 6 и 9 и риск расхождения терминов | средняя | средняя | Строки только через локализацию с первого дня. Таблица терминов RU↔EN в глоссарии (3.2). Проверка полноты переводов в CI |
| РС-12 | Студенты недоступны для юзабилити-теста (каникулы, сессия) | средняя | низкая | Тест в феврале после сессии; при необходимости — проверка с пользователем по сценариям UC |
