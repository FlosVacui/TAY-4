### 4. Новые участки кода
- **Автосинхронизация перед записью** (`finish`, `cmd_build`, `autosync`): при отсутствии xlsx — тихо пропускается и файл строится заново (проверено); при `~$` — sync пропускается, YAML сохраняется, сборка даёт код 2 с сообщением (проверено на `mark`, после закрытия файла следующий `build` подтягивает вписанное «Locked edit»); при битом файле — ошибка до записи (R-0.5-19).
- Сообщения `main` перехватывают `FileNotFoundError`, `YAMLError`, `OSError`, `KeyError/ValueError/TypeError` — трейсбеков нет.
- `parity add/set`: добавление, смена состояния (регистр не важен), неверный подэтап и источник (`--source` из списка 1.1 / К2) отвергаются.
- `merge3`: логика склейки совпадает с описанием (снимок отсутствует → пустая ячейка Excel = «без изменений»).
