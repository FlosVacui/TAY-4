## Что проверено и в порядке
- **Состав ROADMAP 1.0 (критерий 1):** ОС (PLT-001), работа без интернета (PLT-002), установка без прав администратора и переносная сборка (PLT-003), печать и векторный экспорт (USE-001), точность (ACC-001…004), скорость (PRF-001…003). Все на месте.
- **Критерии этапа 2 и Р-9 (критерий 2):** скорость и точность (К1, К3), одинаковые числа (К2), печать/экспорт/формулы (К5), вид и доступность (К4), установка без прав (О3, К7), веб-версия (К13), тесты, CI и упаковка (К6, К8, К7), лицензии, зрелость (К12, К9), пригодность для ТАУ-3 (К10), ИИ-агенты (К11), оплата из РФ (К14). Критериев без источника нет; лишних относительно прежнего списка Р-9 нет.
- **Веса (критерий 3):** суммы пересчитаны вручную: рекомендуемый 100, «Упор на расчёт» 100, «Упор на показ» 100. Значения рекомендуемого набора в §3 и §4 совпадают. Формулировка рекомендации в `DECISIONS.md:11`, `tracker.yaml:1002` и `stack-criteria.md` (К4 = К1 = 12; К3 = К5 = К6 = 10) одна и та же. Срок Р-9 (10.11) совпадает в DECISIONS, tracker (plan end 10.11) и ROADMAP.
- **Подэтапы (критерий 4):** все упомянутые номера (1.1, 1.3, 1.4, 1.5, 1.7, 2.1–2.4, 2.6, 3.2, 3.4, 4.1, 4.2, 4.4–4.6, 5.1–5.10, 6.1–6.9, 8.3–8.6, 8.5, 9.1–9.3) существуют, смысл соответствует (например, 6.8 — локализация и доступность, 8.4 — фаззинг, 8.5 — три ОС и переносные сборки, 4.5 — переносные сборки). У каждого NFR есть проверка и подэтап.
- **Трассировка (критерий 5):** в §7 все 21 NFR из §4 представлены ровно по разу, лишних ID нет, потерянных нет.
- **Противоречия (критерий 6):** Р-6 (Apache-2.0) — MNT-002, О4; Р-8 (RU+EN в 1.0, ЕСПД только на русском) — L10N-001, DOC-001; режим совместимости 1.1 (Бэрстоу, Паде 2/4, РК4) — ACC-003, без битов x87, как в ROADMAP; бюджеты 5.10 (20/10/200 мс) воспроизведены без искажений, оговорка про эталонную машину и случай (R-0.4-11) возвращена в §5.
- **PROCESS, шаблон, tracker:** абзац «Токены» и оговорка в шаге 3 не противоречат остальному тексту; MNT в шаблоне есть в перечне категорий SRS; фраза об опускании «Источник» и «Паритет» оговорена в SRS §4.
- **Факты (критерий 7), три запроса:**
  1. Конец поддержки Windows 10 — 14.10.2025: общеизвестный факт, отдельным запросом не проверялся (лимит запросов израсходован на два других и повтор).
  2. GitHub: стандартный раннер Windows x64 (`windows-latest`) — 4 CPU, 16 ГБ (документация GitHub, «GitHub-hosted runners»). Верно. Попутно: macOS arm64 — 3 CPU, 7 ГБ; это важно для замеров на macOS, если они понадобятся.
  3. GCC (`gcc.gnu.org/onlinedocs/gcc/Optimize-Options.html`): `-ffp-contract=off` в стандартном режиме C (`-std=c11` и т. п.), иначе `fast`. Формулировка stack-criteria.md:86 верна по смыслу (по умолчанию в режиме GNU FMA разрешён). Оговорка: на x86-64 без `-mfma` инструкций FMA нет, на arm64 они есть всегда.
- **Стиль (критерий 8):** русский, короткие предложения, термины глоссария («Паритет», «ворота», «эталон»). Англицизмов без нужды не найдено.
