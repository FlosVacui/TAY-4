# Глоссарий

Термины и обозначения программы и документов. Источник — методичка кафедры АТП и интерфейс оригинала ТАУ-3. Глоссарий дополняется в подэтапах 1.1, 1.2 и 3.2. Названия окон и пунктов меню оригинала даются в кавычках, как в программе.

## Схема и звенья
| Термин | Обозначение | Смысл |
|---|---|---|
| Объект | W | Звено объекта регулирования в прямой цепи |
| Регулятор | R | Звено регулятора в прямой цепи |
| Главная обратная связь | H | Звено главной обратной связи. На его входе y + z |
| Местная обратная связь | G | Звено местной обратной связи вокруг R. Её вход — u |
| Нелинейность | N | Нелинейное звено между R и W. Тип 1 означает линейную систему |
| Воздействия | f, g, v, z | f — задание; g — возмущение, прибавляется к выходу W; v — прибавляется между первым и вторым блоком прямой цепи (при схеме «R» это вход N, при схеме «N» — вход R); z — помеха измерения на входе H |
| Точки размыкания | h, x | h — выход H, разрыв главной обратной связи: Wраз = HRW/(1+RG). x — выход первого блока прямой цепи до сумматора v (R при схеме «R», N при схеме «N»): Wраз = (HW+G)R. Wраз — передаточная функция разомкнутой системы, W — звено объекта. Подробно: `work\control\notes\f_process.md` §0–2 |
| Буквенные параметры | A, B, C, D | Вместо числа в поле параметра ставится буква. A и B действуют везде, C и D — только в процессе и поиске минимума |
| Метки NL / NG | NL, NG | NL — нелинейность N не типа 1; NG — у звеньев W, R, H, G есть параметр, начинающийся с «-» |
| Аппроксимация Паде | — | Замена e^(−τp) дробью 2-го или 4-го порядка там, где нужен многочлен: корни, Раус |

## Виды исследования
| Термин | Смысл |
|---|---|
| Корневой годограф | Траектории корней характеристического многочлена при изменении A (а в CONTROL 2 и K) |
| Критерий Рауса | Таблица Рауса; число корней в правой полуплоскости. Сетка A×B — по каждой паре значений |
| Критерий Найквиста | АФХ разомкнутой системы и точка −1. Кривая Попова — (Re W, ω·Im W) |
| ЛАЧХ, ЛФЧХ | Логарифмические амплитудная и фазовая частотные характеристики |
| АЧХ | Амплитудная частотная характеристика замкнутой системы |
| Процесс регулирования | Переходный процесс во времени при заданных воздействиях |
| Поиск минимума | Перебор A×B по критериям I₁ = ∫\|e\|dt, I₂ = ∫e²dt и tрег |

## Показатели качества
| Обозначение | Смысл |
|---|---|
| σ | Перерегулирование, % |
| tр | Время регулирования (полоса ±5 % или ±2 %) |
| hуст, ε | Установившееся значение и установившаяся ошибка |
| η | Степень устойчивости |
| μ | Степень колебательности |
| ψ | Степень затухания |
| M | Показатель колебательности |
| ωср, ω180 | Частота среза; частота, на которой фаза равна −180° |
| Kкр, ωкр | Критический коэффициент и частота на границе устойчивости |

## Процесс разработки
| Термин | Смысл |
|---|---|
| График работ | Excel-файл `docs/tracker/ТАУ-3_NG_график.xlsx`. «Диаграмма» — график функции в программе |
| «Паритет» | Лист графика работ: каждая функция и поведение 1.1 и CONTROL 2 и их состояние в новой программе |
| Оракул | Независимый источник эталонных чисел: Delphi (ветка `oracle`) или mpmath |
| Ворота | Приёмка этапа целиком перед переходом к следующему |
| Развилка (Р-x) | Вопрос, который решает пользователь |
| ВН-xx | Запрос во внешнюю нейросеть, который пользователь отправляет сам |
