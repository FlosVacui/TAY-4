# ТАУ-3 NG — CONTROL

Название рабочее, окончательное выбирается в развилке Р-0.

ТАУ-3 NG — новая версия программы CONTROL из учебного пакета ТАУ-3 «Теория автоматического управления». Авторы оригинала — О. Е. Лозинский и Я. М. Берщанский, 2005. Программа исследует замкнутую систему автоматического регулирования: критерии Рауса и Найквиста, корни и корневой годограф, частотные характеристики, процесс регулирования, поиск оптимальных настроек, показатели качества.

**Цели:**
- работа в Windows, Linux и macOS;
- современный понятный интерфейс;
- сохранение всех возможностей оригинала и их расширение;
- расчёты, проверенные независимыми эталонами.

## Состояние
Этап 0 — подготовка: правила, учёт, документы. Кода программы пока нет. Стек выбирается на этапе 2.

## Происхождение
CONTROL был разобран и воссоздан на Delphi. Это отдельный проект вне репозитория: точная копия 1.1 и расширенный CONTROL 2. Delphi-версии служат эталонами при проверке новой программы. Материалы оригинала ТАУ-3 (исполняемые файлы, справка, снимки окон) в этот репозиторий не входят.
